# losbatracios.com

The website for *Los Batracios*, the feature film I wrote, produced and directed (Audience Award, Mammoth Lakes Film Festival 2025).

**Live:** [losbatracios.com](https://losbatracios.com) · [English](https://losbatracios.com/en/)

The brief I gave myself was simple: a page that looks like the film, loads instantly on a phone, and turns visitors into an audience I can reach again.

## What's inside

- **One source, two languages.** `build.py` generates the Spanish site at `/` and the English one at `/en/` from the same content, plus privacy pages, sitemap and robots, with hreflang between them.
- **SEO done properly.** Unique titles and descriptions, Open Graph and share images per language, `Movie` structured data with awards and cast, canonical URLs, verified in Google Search Console.
- **Fast.** Static HTML with responsive WebP images and no framework.
- **Mailing list.** A Cloudflare Worker, generated by `build.py`, receives sign-ups, checks them with Turnstile, adds them to Buttondown with a language tag, and sends a welcome email.
- **I know where people come from.** Short links (`/ig`, `/tt`, `/qr`, `/prensa`…) tag each channel, posters included. Analytics run on Umami, which is privacy-friendly and needs no cookie banner. `/resena` sends people leaving a screening straight to Letterboxd.
- **Security.** Secrets live only in Cloudflare environment variables, and the code went through a security review before launch.

## Stack

Python (build) · HTML/CSS · Cloudflare Pages + Workers · Turnstile · Buttondown · Umami

The code comments are in Spanish.
